# Security

Revision: 2026-10-11

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/onlinesourdough/OSM-plugin/security/advisories/new).
Do not open a public issue for them.

Include the affected OSM version, a sanitized reproduction and the impact.
Do not include real secrets, credentials or personal data.

Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/onlinesourdough/OSM-plugin/issues).
