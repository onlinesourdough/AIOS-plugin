# Resolve a choice with a local trial

Use when an unresolved choice materially affects the result and a cheap local
observation can distinguish plausible approaches, or concrete alternatives are
requested. Reuse accepted intent and existing evidence. A clear task can go
straight to production; do not invent alternatives to fill this procedure.

Name the decision and the observation that could change it. Choose the smallest
useful trial within the task's time, cost and action authority. One experiment
may settle a behavior question; comparing designs may need several variants.
There is no fixed candidate count, canvas, stack or agent fan-out. Keep ordinary
exploration in the current session.

Use a task-local scratch folder or a working copy with synthetic data where
useful. Preserve existing source and user edits. A mock or trial does not prove
production readiness and cannot expand account access, publication or deployment
authority.

- **Visual direction:** use an installed design method if the host provides
  one; otherwise do the work directly or report the missing method. Show
  comparable variants on an available canvas or browser surface when that helps
  the decision; this procedure does not require a new editor.
- **UI/UX behavior:** use the smallest runnable flow that exposes the uncertain
  interaction. Exercise it through the available browser/app tools. Static
  screenshots can compare appearance but cannot establish interaction usability.
- **Other work:** a sample content treatment, synthetic workflow walkthrough or
  small script can resolve a concrete fork. Observe the relevant output or
  behavior; don't manufacture a software prototype for an editorial choice.

Separate observations from inference and preference. The agent should settle
facts it can inspect; only the user can supply an unresolved personal/product
preference. If observation is unavailable, report the missing evidence rather
than claiming the trial ran. Continue independent authorized work.

Recommend one coherent direction against the task's success criteria. Preserve
useful evidence and limitations in the existing task/contract; no mandatory
schema or second live plan. Stop when the choice is sufficiently resolved or
further trials would add little within the agreed bounds. Reopen it only for new
evidence or a user correction. Pass the selected direction to the original
production/review method; any retained trial artifact stays clearly provisional.
