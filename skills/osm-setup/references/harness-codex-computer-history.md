# Codex Computer History

Read only when the user asks to inspect or configure Computer History. Apply the
shared [configuration procedure](harness-configuration.md). Workspace availability
is not personal consent; preserve an off choice and require explicit opt-in and
source selection.

Inspect the native Computer History control independently of Computer Use. The
current macOS flow is Settings > Integrations > Computer history, with include-
only/exclude source controls. It requires native Memories; do not enable either
automatically to complete OSM. History does not require the Computer Use Screen
Recording grant.

Use the current [Computer History guide](https://learn.chatgpt.com/docs/customization/computer-history)
for that client's availability and controls. Verify the visible setting and
chosen source scope; do not invent a config.toml key or copy opaque app/history
state. Availability, opt-in, source permission and observed collection are
separate claims. Do not collect personal activity just to test setup. If an
owner-authorized synthetic verification is unavailable, label collection NOT
VERIFIED and leave core OSM usable. History is never canonical OSM context.
