# Repository specialist skills

Revision: 2026-10-11

Keep only concrete, repeatable methods specific to this repository or its
domain, with their evals, at `.agents/skills/<name>/SKILL.md`. Generic
specification, build, review, release and audit methods are not kept here;
contributors use their own harness methods under the root
[AGENTS.md](../../AGENTS.md) contract. Do not copy, wrap, rename or symlink the
shipped product skills from `skills/` into this shelf.

For a concrete specialist gap, inventory existing repository-local and
harness-native capabilities. Reuse a sufficient method; install external skills
through the chosen harness under explicit authority. External methods remain
owned by their maintained source; historical Global Skills are archived.

No repository-specific skill is currently needed. Add one only for a concrete
repeatable specialist responsibility.
